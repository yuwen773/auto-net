## 已有契约

- UI 与服务间继续通过 status.json 传递状态。UI 不代替服务判定认证成功，不清空未知结果或绕过持久暂停。
- 普通用户托盘与管理员操作分离；设置和 DPAPI 凭据仍走既有权限与存储路径，保存设置不会解除认证暂停。
- 关闭主窗口隐藏到托盘；退出 UI 不停止服务。固定安装路径、启动参数、自启与升级保留数据的行为需要兼容验证。
- 浏览器兜底沿用服务授予的标志与冷却契约，只打开门户页、不自动填表或携带凭据。通知强度的选择不等于改变浏览器兜底条件。
- 现有浅色 WinForms 已有圆角、语义色和扁平按钮，不能把这些能力重复计作迁移成果。
- 不因本次迁移自动扩大日志中心的历史检索、聚合或保留策略范围。
- 领域词表沿用 `79ccc02` 的既有定义，并在根目录 CONTEXT.md 补充已确定的“关键通知”；该文档引入不代表服务源码已合入当前 UI 分支。

## 交互契约核查

- 服务在授予浏览器兜底时立即置标志，并把 `BrowserFallbackNotBefore` 写为授予时刻加 10 分钟；现有代码、ADR 和测试没有明确首次打开是否必须等到该时间。单次授予内时间戳稳定，服务重启会重新授予；status.json 不含故障 ID 或浏览器消费确认。首次时机与跨重启去重不能由 UI 静默猜定。
- 现有诊断包 CLI 不自动提权：有权限时读已保存设置，普通权限下会标注缺失并回退当前连接配置。导出只读、不加载凭据，但包含网络探测流量。既有库可能覆盖同名文件，仅在采集阶段保证取消不创建 ZIP；不能直接宣称任意阶段取消或失败都保留旧包且不留半包。

## 收敛后的交互约束

### 页面与状态

- 概览优先呈现当前网络状态、AutoNet 正在做什么及下一步操作；技术详情可展开，完整诊断项在网络诊断页。在线与认证暂停可以同时存在，不能用暂停覆盖实际联网状态。
- 缺失、过期、损坏或不可信的状态显示为状态不可确认；禁用依赖可信状态的恢复开关和解除入口，不沿用上次在线画面或猜测服务成功。
- 门户改版信号只说明结构疑似变化，不自动等同认证已暂停；暂停与重试仍服从后台实际状态。
- 日志首版保留已有日期查看、受限列表、详情、复制与打开目录等能力，并明确展示当前读取范围。跨天检索、聚合统计、保留策略调整不自动纳入本轮。
- UI 主题与消费记录按 Windows 用户保存，独立于管理员专用的业务设置和凭据；不在 UI 偏好中保存账号密码、Cookie 或 Token。

### 通知与浏览器

- 首次读取状态时不重播历史恢复；若当前认证仍暂停，提醒一次。运行中需要人工处理的关键事件提醒一次，复检进度只在界面显示；不建立定时重复提醒。
- 通知去重记录与浏览器消费记录分开：通知未弹出或被系统抑制，不等于浏览器请求未处理；浏览器打开也不等于认证成功或认证阻断已解除。
- 有效浏览器兜底请求首次立即打开固定允许的门户根地址，只开页、不填表、不携带凭据；重读可信当前状态确认请求仍有效后才启动浏览器。首次语义及冷却见 [ADR-0008](adr/0008-browser-fallback-first-open.md)。
- 同一授予只自动打开一次，消费记录跨托盘重启保存；手动开页计入消费与冷却。服务重启可能换发授予，UI 仍保留本地 10 分钟自动开页冷却，不将服务重启当作绕过去重的理由。时间到期本身不产生再次自动打开：仅新授予可触发后续自动开页，且须满足冷却；持续有效请求保留手动开页入口。
- 启动浏览器失败显示受控错误并提供手动重试，不因轮询或托盘重启不断弹页；不改变服务端认证和主动断线策略。

### 诊断包

- 用户主动触发后，以普通界面打开保存对话框，默认当前用户桌面；显式选定路径后再启动单独的提权导出操作，避免提权身份变化导致落点改变。
- 取消保存或拒绝 UAC 不导出；同名文件覆盖前确认。导出失败或取消不破坏原包、不向用户交付不完整 ZIP；需要补齐现有导出库的安全写入和取消保证，并增加对应回归。
- 提权提供读取已保存设置的权限，不保证所有网络采集成功；既有超时或缺失项降级继续保留，必须在 README 和 UI 结果中明确说明。
- 导出只读、不加载凭据、不解除阻断；允许现有只读探测流量，不执行连接、断开或认证提交。输出沿用既有脱敏契约。
