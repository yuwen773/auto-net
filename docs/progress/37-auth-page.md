# #37 上网认证页与浏览器宿主抽象

2026-10-29 在 `codex/ui-avalonia` 的 `4699c24` 基础上实施，2026-10-30 按审查意见修复。工单 #37 只交付页面、宿主抽象与受控提示；#38 的认证页网络边界与 #39 的后台会话附着仍开放，本地代码存在不代表它们已完成。

## 实现

- 新增左侧导航「上网认证」（位于「概览」之后），导航目录仍是单一来源；页面模型只做状态投影，不读取配置、不访问网络。
- 状态分为联网、认证成功、提交结果未知、自动恢复已关闭、等待重试、需要人工与状态待确认；联网事实优先于残留的认证暂停，不可信/缺失状态降级为待确认。
- 结果未知的文案区分两件事：后台继续只读复检；只有在外网不可达且共享提交额度与最短间隔仍允许时，才可能进行有限自动重试，否则不会重发凭据。打开、刷新、切页、最小化本身都不构成提交意图。
- 明确的人工信号优先于结果未知：提交消解存储故障、门户结构疑似变化、浏览器兜底请求、终止性认证暂停，以及服务已发布“提交额度已用尽”时的额度耗尽。额度耗尽只识别服务受控文案中的“提交额度已用尽/两次额外额度已用尽”，不会把“主动断线额度已用尽”误判为提交额度；未命中时保持一般结果未知，不猜测额度。
- 外网已恢复时按联网展示，不再显示结果未知；若快照仍保留待消解提交，只补充“当前不会重新提交”的事实，不把联网恢复说成认证成功。
- 恢复开关关闭与“等待重试”分开投影：服务关闭恢复且外网不可达时发布“已暂停恢复”，页面显示“自动恢复已关闭”，说明后台仍检测网络但不会重连或自动提交凭据，并指引到概览页开启自动恢复；页面本身不提供开关或提交动作。只有开关开启时才显示“等待重试”及其自动认证说明。
- 暂停与待消解提交并存时，页面只陈述“上次提交结果仍未确认、后台只做只读复检、不会重新提交”，不再出现“可能有限自动重试”；存储故障、额度耗尽等人工信号与暂停并存时，同样不承诺自动重试（额度耗尽还说明即使开启恢复也不会自动重发）。
- 缺少凭据与缺少设置不再落到“等待重试”：服务在 Wi-Fi 就绪、外网不可达且没有凭据时发布受控文案“未保存认证信息”，页面据此显示“需要保存认证信息”，说明后台不会发出认证请求并指引到设置；服务状态为“等待设置”时显示“尚未保存设置”。两者都只依据可信快照中的受控字段/文案，不读取、不猜测、不回显账号密码；文案未命中时保持等待重试或待确认，不推断凭据是否存在。
- `IAuthPageBrowserHost` 只有加载固定门户根地址、显示/隐藏与销毁三类能力，没有填表、脚本或提交入口。页面模型与回归只依赖该接口，假宿主即可覆盖生命周期。
- 打开页面只附着一次；普通状态刷新、切页、最小化、恢复与关闭只重新投影或改变可见性，不重新导航、不丢已填内容，后台状态读取继续运行。
- 生产宿主在 #38 网络边界接入前失败关闭：不创建浏览器、不发起网络请求。WebView2 运行时缺失返回 `RuntimeMissing`，运行时存在但边界未接入返回 `NetworkBoundaryUnavailable`，附着异常返回受控 `Failed`；三者都显示手动重试，不自动重试，也不回退直连。
- 宿主状态以宿主自身快照为准；附着异常产生的失败投影只在宿主状态变化或用户显式重试前保留，不会被后续刷新误报为成功。
- 状态卡由横向 StackPanel 改为 Grid，给长文案受约束的宽度；否则结果未知的额度/间隔说明会被卡片裁切而不是换行。

## QA 互斥接口（供 #41 统一集成）

- 环境变量：`AUTONET_QA_MUTEX_SUFFIX`。
- 本工作树规则：只在 QA 激活（`AUTONET_QA_DIR` 非空）时生效；后缀只接受 ASCII 字母、数字与连字符，最长 32 字符；非法或空后缀回落到固定 QA 名 `Local\AutoNet.Tray.Avalonia`；有效时拼接为 `Local\AutoNet.Tray.Avalonia.<suffix>`。解析集中在 `QaEnvironment.MutexSuffix`，`Program.ResolveMutexName` 只消费该属性。
- #41 工作树规则：同一环境变量，但解析写在 `Program.ResolveMutexName`，字符集为字母/数字/连字符、未限长，非法值回落固定名。
- 集成建议：保留一份解析器（优先 `QaEnvironment.MutexSuffix`）与 32 字符上限；两边的 QA 后缀都由字母/数字/连字符组成，合并时不需要改脚本。认证页 QA 使用 `q` + 证据目录 SHA256 前 16 位小写十六进制。
- 本机已安装的 0.3.1 候选托盘仍占用固定 QA 名；QA 脚本用后缀隔离，未停止或替换已安装进程。
