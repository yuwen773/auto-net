# #36 旧数据兼容与升级回滚实施记录

日期：2026-10-31，分支 `codex/ui-avalonia`，起点 `8ad3acd`。依赖 #31、#32 已在本分支落地的提交额度与有限重试实现；对应 GitHub 工单的本地结果不代表发布或实网验收。

## 结论

历史认证记录与回滚行为已由生产代码保守实现，本轮不改变持久格式，只把契约固化为回归，并冻结已发布 v0.3.1 的读取规则用于回滚验收。决定见 [ADR-0020](../adr/0020-legacy-state-upgrade-rollback.md)。

- 64 位十六进制指纹、失败-only（无 `Version`）、缺字段、未知版本、未知状态、越界次数、损坏 JSON、非对象 JSON：一律读成阻断块，零凭据提交，且不生成 `submission-budget.json`。
- 读取不迁移：运行、重启、检测都不会改写或删除旧记录字节，原始证据保留。
- 升级路径：旧记录经修订比较写入转成当前记录时保留阻断；失败-only 记录保留原始失败分类。
- 回滚路径：提交结果未知时 `auth-block.txt` 自身是 `SubmissionPending`，v0.3.1 读到它同样拒绝提交；旧版本忽略独立额度文件，对提交未知/终态记录退回 ADR-0001 的永久暂停，不会重复提交，也不会获得新额度。冷却与就绪记录表示尚未发出凭据或已确认成功，旧版本按自身上限继续，不属于重复提交。
- 回滚遗留的耗尽额度不因人工解除暂停而清零；重新升级后仍按 `Exhausted` 停止提交，只有 #34 的审计重置能清零。

## 实现

新增 `tests/AutoNet.Tests/LegacyStateRegression.cs`，在 `Program.cs` 注册，7 项：

1. 指纹形状仍按人工暂停、零提交、零额度、字节不变；
2. 失败-only 记录（含字符串枚举与越界失败值）仍按人工暂停、不写额度；
3. 缺字段、未知版本、未知状态、越界次数、损坏/非对象 JSON 的矩阵，逐项核对记录形态与阻断；
4. 升级路径：旧指纹/失败-only → 当前记录，阻断与失败原因保持；外网在线轮次不改写旧记录，升级写入失败时旧记录原样保留（失败点确实在原子替换，读取仍成功）；写入走的就是生产使用的修订比较写入；
5. 回滚：真实 Worker 制造 `SubmissionPending` + 额度 1，冻结的 v0.3.1 读取规则仍拒绝提交；
6. 回滚：新终态（绑定拒绝、凭据拒绝、交互要求含通道原因、安全持久化失败）仍阻断；冷却/就绪记录不阻断但次数不被改写；当前记录必须保留旧版七个字段名、额外字段只限旧版忽略的已知扩展；未知状态、未知失败分类与未知版本在旧版眼中必须仍是未知值并被阻断；
7. 回滚：三次额度结束后解除暂停，重新升级仍零提交、额度不变。

冻结读取器 `ReadAsReleasedV031` 复制 v0.3.1 的字段集合、枚举值与一致性判定，并固定旧枚举值快照：未来新增状态或失败分类在旧版视角必须仍是未知值。新增的 `ChannelFallbackCause` 与派生的 `BlocksSubmissions` 按旧版行为被忽略。

未修改 `SafetyStateStore`、`MonitorWorker` 或任何持久格式。

## 审查

两轴审查（固定点 `8ad3acde`，提交 `85b1574`）的发现与处置：

- **Standards**：无硬性规范违反。判断项“冻结读取器复用当前 `AuthenticationBlock` 类型且缺少 `JsonException` 捕获”已修复：补齐与 v0.3.1 相同的捕获，并在注释中固定来源（tag `v0.3.1`）与漂移边界。额度文件名不再硬编码为单一文件名，改用前缀匹配，改名后仍能发现残留。
- **Spec**：三处部分覆盖已补强——
  1. “升级写入失败”原先在读取阶段就失败，断言形同虚设；改为持有句柄时只拒绝 Delete 共享，使读取照常成功、原子替换在写入处失败，并显式断言读取成功，失败点确实落在写。
  2. 枚举值快照此前没有任何用例喂入越界值；现补未知状态、未知失败分类与未知版本三种输入，旧版视角必须仍判为阻断。
  3. 记录形状契约此前无约束；现断言当前记录保留旧版七个字段名各一次，额外字段只限旧版忽略的已知扩展。
- ADR 中“不会重复提交”的表述此前已收窄为只对提交未知/终态记录成立；本次进一步把“新增字段”规则写成可检验的字段名契约。无范围外功能改动。

## 限制

回滚不是热切换：应先停止服务并保留受限目录状态。旧版本不理解 `submission-budget.json`，恢复的是永久暂停语义；真实安装器回退流程仍按 `docs/VALIDATION.md` 的安装、权限与回滚验收表单独执行。
