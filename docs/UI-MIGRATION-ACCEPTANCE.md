## 状态口径

- **通过**：有可复核证据（脚本、产物路径、提交号）支撑该层结论。
- **失败**：该层已执行且未达到规格（必须写明缺口与去向）。
- **未执行**：该层尚未获得证据；不得以其他层证据或截图补为通过（T20 分层原则）。

证据层：

| 层 | 含义 | 典型证据 |
|---|---|---|
| 工程回归 | 仓库内自定义测试运行器（`tests/AutoNet.Tests`）+ Release 构建零警告零错误 | `artifacts/validation/tests.txt`、`build.json` |
| 受控桌面 | QA 脚本驱动的真实进程/窗口证据（本机受控环境，不安装不部署） | `artifacts/validation/ui-avalonia-*/` |
| 真实桌面（人工） | 用户真实桌面环境的视觉/交互确认（托盘菜单、读屏、真实系统明暗、真实 DPI） | 待人工 |
| 真实安装/回退 | 覆盖安装、ACL、自启、数据保留与旧包回退（需单独授权，工单 #16） | `artifacts/validation/issue16-evidence/`（2026-10-17，本地证据不入库） |
| 真实网络 | 断网、认证失效、TUN/UU 共存、恢复性能（破坏性，需单独授权） | 待 #16 后独立验收 |

## 构建标识与证据对应（T18）

候选包 `artifacts/AutoNet-win-x64/`：

- 包内 `BUILD-ID.txt`：程序版本（ProductVersion，含提交哈希）、源提交、构建时刻、SDK、回归结果、预览边界。
- 包内 `build.json` / `tests.txt`：与包对应的构建与全量回归证据（与 `artifacts/validation/` 同源复制）。
- 包内 `SHA256SUMS.txt`：覆盖包内全部文件（清单不含其自身；`BUILD-ID.txt` 在列）。
- 发布门槛：干净工作树（`git status --porcelain` 为空），保证包 ↔ 提交一一对应。
- 托盘发布身份：`src/AutoNet.Tray.Avalonia` + `-p:AutoNetPublishIdentity=true` → `tray/AutoNet.Tray.exe`（安装契约不变，工单 #3）。
- **预览与正式安装明确区分**：预览 = 直接运行 `tray\AutoNet.Tray.exe`，不安装、不替换程序、不停止现有服务；覆盖安装须按工单 #16 单独授权执行。
