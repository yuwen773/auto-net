# 认证页展示嵌入：NativeControlHost 承载只读门户页

2026-10-30，实施 [#38](https://github.com/yuwen773/auto-net/issues/38)，接续 [ADR-0009](0009-embedded-auth-channel.md)。本条只覆盖「上网认证」页的**只读展示**，不改变 ADR-0009 对凭据提交载体的决定。

## 决定

- 「上网认证」页用 Avalonia `NativeControlHost` 在主窗口内承载 WinForms WebView2，加载固定门户根地址。页面不填表、不提交凭据，也不注入任何会改写页面的脚本；唯一允许的脚本是下面 2026-11-22 记录的**只读尺寸测量**。填表与提交仍只属于独立辅助进程的内嵌认证通道（ADR-0009）。
- WebView 的网络连接经进程内的环回允许列表代理：完整主机匹配、明文只允许 80、CONNECT 只允许 443、拒绝请求体与协议升级；出站连接经 `DirectNetwork.ConnectAsync` 用 `IP_UNICAST_IF` 加源地址绑定钉到校园网卡。代理不可用时失败关闭。
- 2026-11-22：固定门户根页初始化依赖同一主机的 HTTPS 802 脚本、只读配置及主题资源。托盘按资源类型、路径和查询参数允许列表拦截这些文档子资源请求，以绑定同一校园网卡的 HTTPS GET 读取后把内容交给 WebView。TLS 校验保持开启，禁止重定向，不转发浏览器请求头、Cookie 或请求体。浏览器不能经代理建立 802 隧道，资源处理器不接收登录、注销、顶层导航或其他端点。
- 2026-11-22：门户页固定设计宽度约 1200 CSS 像素，承载盒比它窄时会出现横向滚动条。为此展示页在导航完成后执行**一次只读尺寸测量**（`AuthPageZoom.MeasureScript`：只读 `documentElement.scrollWidth/scrollHeight` 与视口宽高，返回四个数字），据此把 WebView 的 `ZoomFactor` 收进盒内（浏览器缩放语义，不重排、不改写页面）。测量在 `ZoomFactor=1` 时进行，加载稳定后最多补测一次，窗口尺寸变化后防抖再测；任何失败都只回落到 1.0，不改写页面状态。脚本是固定常量，不读表单、凭据、cookie 或存储，不发请求；回归测试逐字钉住这两条性质。除此之外页面仍不注入任何脚本。
- 浏览器参数只作用于这个 WebView（`--proxy-server`、`--proxy-bypass-list=<-loopback>`、关闭 QUIC 与 WebRTC 非代理 UDP），不读取或改写系统代理。
- 网卡来自后台服务发布的可信状态投影（`status.json` 的配置投影），不从普通权限读不到的 `private/settings.json` 取值。

## 为什么不沿用 ADR-0009 的「放弃嵌入」

ADR-0009 放弃的是把**凭据提交通道**嵌进主窗口：那时混合宿主没有成熟先例，而通道要处理密码、自动填表与提交，风险不可接受。展示页不接触凭据，原型已用 `NativeControlHost` 承载 WebView2 并核验原生父子关系；工程风险因此只落在呈现层，可由代理边界与失败关闭独立兜住。

## 边界

- 展示页与内嵌认证通道不共享会话、cookie 或用户数据目录；展示页使用一次性临时目录，失败或重试时丢弃。
- 本决定不声称真实门户页面、TLS、重定向、新窗口或 Service Worker 已验证；这些仍需现场验收（见 `docs/VALIDATION.md`）。
- **WebRTC/STUN 的实际走向未查清**：浏览器参数关闭了 QUIC 与非代理 UDP，但没有现场抓包证明所有 WebRTC 流量都被代理或阻断，不能据此声称已被拦截。该方向保留为现场验收项。
- 若将来要让展示页承担填表或提交，必须新开 ADR，不得把它当作 ADR-0009 通道的替代。
