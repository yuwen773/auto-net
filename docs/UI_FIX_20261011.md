## NEW-01 及复审建议补充修复

基于已推送的 `7e3ab25` 继续修复：

- NEW-01：主窗口与托盘菜单共用操作状态；不可信快照显示“自动恢复状态待确认”并禁用。打开托盘菜单及点击时重新读取快照，点击时已过期或丢失则不产生设置命令。外部 JSON 缺少明确的 Enabled 字段也不可用于决定恢复操作。
- 操作意图：可信状态下发送 `--enable-recovery` 或 `--disable-recovery`，管理员进程读取最新配置后设置为指定值，保留其他设置；相同命令重复执行不会反转状态。旧 `--toggle` 与同时开启/关闭的矛盾命令被拒绝。
- P2：技术详情中的 PortalStage、PortalFailure、AuthenticationState 必须匹配枚举规范名称；自由文本、数值和未来枚举值统一显示“未知”，不改变独立联网事实。
- P3：将初次验证时的“未提交/未推送”改为历史阶段描述，并补充已核实的提交与 CI 链接。

新增 5 项回归：主窗口可信/失效状态、实际托盘菜单入口、点击与授权期间的状态变化、明确命令的幂等执行及其他配置保留、技术字段白名单。修复前的定向测试复现主窗口与托盘两个失败（0/2）；修复后 NEW-01 定向测试 4/4 通过；Release 构建零警告、零错误，完整回归 **153/153 passed**。完整结果见 `artifacts/validation/tests.txt`、`build.json`。
